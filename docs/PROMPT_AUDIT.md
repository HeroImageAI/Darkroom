# Phase 1 — Prompt audit

Date: 2026-09-29. Status: **proposal only — nothing below has been applied.** Every internal prompt, template, preset,
negative and rewrite step found in the codebase is listed with a proposed replacement that follows how the target model
actually works. Rewrites become code in Phase 1 of [PLAN.md](PLAN.md) after approval.

## C. Routing rule (no cross-contamination)

All prompt text is composed in one pure module, keyed by `(model, mode)`:

```
composePrompt(model: 'klein'|'qwen', mode: 'generate'|'ref'|'instruct'|'inpaint'|'outpaint', parts) → string
composeMotion(model: 'wan'|'ltx', parts) → string
```

Templates live in `presets/prompts.json` (user-editable, shape validated at load). Unit tests assert: every
(model, mode) pair has a template; no Qwen-only token (`<imageN>`, `Style:`, quality tail) appears in a Klein output and no
Klein-only phrasing appears in a Qwen output; captions are never taken from edit instructions.

## D. Verification plan for the rewrites (part of Phase 1)

Fixed-seed A/B, old vs new prompt, for each row that changes image output (P1–P5, P11, P13): 3 subjects × 5 styles ×
2 models for styles; 2 edits × 2 models for P3; 2 clips × 2 models for P4/P5. Grids go to `docs/qa/phase1/` and into
QA_REPORT.md. A rewrite is kept only if it is equal or better on the grid; otherwise the old text stays and the result is
recorded.
