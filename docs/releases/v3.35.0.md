# Darkroom v3.35.0

Reliability and Library improvements based on workstation testing. Existing creative workflows and model defaults remain available.

- Timeline flushes pending saves on navigation, serialises writes, and exposes save status with retry on failure. Abrupt browser/process termination is not guaranteed to save.
- Ripple deletion closes gaps correctly when following clips overlap the deleted clip.
- Completed video takes display the stored output dimensions, frame rate and duration rather than requested settings. Duration uses encoded frames / fps when available.
- GPU memory uses GiB, correctly showing a 24 GiB RTX 3090.
- Library sorting (newest, oldest, name, largest image area) applies to the complete result set before pagination. Counts distinguish stacks from versions; changing the view clears stale selection.
- Timeline outputs link back to their originating film. Multi-stage video operations label their recorded time as final-stage time.
- Lucida background removal is unavailable until its model is installed. Qwen reconstructed layers explain their 640 px working resolution and the source-pixel SAM alternative.

Validation: TypeScript check, production build and regression tests for saves, overlapping ripple deletion, metadata and Library ordering. This release does not change generation workflows, reinstall models, or repeat the earlier full generation matrix. Affinity import and sustained thermal behaviour remain outside this release's validation.

Release validation: 496 tests passed across 38 files; TypeScript and production build passed. Live smoke check confirmed a film rename persisted after immediate navigation, Library sorting cleared stale details, and GPU memory displayed 24 GiB. The build retains its existing large-bundle warning.
