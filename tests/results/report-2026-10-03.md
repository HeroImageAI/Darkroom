## 3. Recommended defaults (Apparel, provisional — one seed)

- **Sketch → render, material swaps, print placement, inpaint, style:** Klein 9B.
- **Multi-view / presentation boards:** Qwen-Image 2.1.
- **Text on the image (labels):** neither is reliable yet — add labels outside Darkroom.
- **Video:** start from an on-model or in-context render, keep one action per clip.

## 4. Findings — UI / feature gaps

1. **The seed lock resets after every Edit run.** Steps: Edit → Seed 42 (locks) → Apply → Edit opens the new version
   with a new random, unlocked seed. Seed 42 *was* used (Details shows it), but the next run would not use it
   unless retyped. Screenshot: `screenshots/APP-IMG-01/APP-IMG-01_Klein_s42_result.png`.
2. **A version stays in its source's board.** Inputs uploaded to *00 Inputs* would pull every edit of them into
   *00 Inputs*; inputs were therefore uploaded into the industry board and *00 Inputs* is empty.
3. **One stack per input grows very large.** All jacket tests sit in one stack of 33 versions, whose cover is the
   newest item — currently a **video** (APP-VID-05). Browsing one test's result needs titles/search. Screenshot:
   `screenshots/pilot-apparel-board-stacks.png`.
4. **Enhance has no prompt box** (APP-IMG-07): run as Darkroom's *Restore* plus an Instruct with the suite prompt.
5. **Video has no seed control**: video runs are not reproducible.
6. **Video crops a 3:2 source to 16:9** by default ("Crop to fill"); "Fit with bars" is the alternative.
7. **On-model / on-foot source frames** do not exist in the suite's chain (APP-VID-01/02/03): an Instruct step was
   added and stacked (ADAPTED).
8. **APP-IMG-07 input** is a clean 800×1200 product shot, not a low-res phone photo, so it cannot show how much the
   models sharpen.

- The seed-lock reset (finding 1) was the closest to a bug — **fixed in v3.20** (a locked seed stays locked).
