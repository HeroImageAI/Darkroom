## 2. Summary per model

| | Average | Strong at | Weak at |
|---|---|---|---|
| **Klein 9B** | **3.90** | re-presenting a design (clay, marker, exploded, chrome, genre and media swaps), inpaint blending, outpaint, multi-step chains that stay stable (AUT-IMG-07) | following a sketch's exact proportions (AUT-IMG-01), layouts with an exact count, labels |

| **LTX 2.5** | 3.13 | in-place transitions with a start/end frame (clay → product, sketch → car), product reveals, a camera that pushes or glides | full 360° turns (gets 30–270°), named camera moves (orbit, crane, static) often ignored, keeping fine design detail when the view changes |

## 3. Recommended defaults (provisional — one seed)

- **Sketch → render where the proportions must hold** (footwear, automotive): **Qwen**, then switch to Klein for
  everything built on that render.
- **Material, colour, style, clay / marker / exploded, genre and lighting moods, inpaint, outpaint:** **Klein**.
  Exception: lighting changes on a cinematic frame are slightly better on Qwen.
- **Turnaround / multi-view sheets:** **Qwen** for characters and apparel; **Klein** for product boards (Qwen
  returned the car unchanged).
- **Sheets with labels or an exact count of items:** neither model is reliable — make the grid outside Darkroom or
  ask for fewer items.
- **Video:** use a start/end pair for any transformation (scores 4); keep one simple action per clip; expect a
  partial turn instead of a 360°; feed at least 720p sources (upscale small crops first).

## 4. Findings — UI / feature gaps

1. **The seed lock reset after every Edit run** — fixed in v3.20.
2. **A version stays in its source's board.** Inputs were uploaded into each industry board; *00 Inputs* is empty.
3. **One stack per input grows very large** (the jacket stack has 33 versions; the cover is the newest item).
4. **Enhance has no prompt box** (APP-IMG-07, FTW-IMG-08, GAM-IMG-08): run as *Restore* plus an Instruct (ADAPTED).
5. **Video has no seed control**: video runs are not reproducible.
6. **Video crops a non-16:9 source to 16:9** by default; "Fit with bars" is the alternative (used for MOV-VID-04).
7. **On-model / on-foot / three-quarter source frames** do not exist in the suite's chain: an Instruct helper was
   added (APP-VID-01/02/03, FTW-VID-02, AUT-VID-01).
8. **Several inputs differ from the suite's description** (clean renders, not phone photos; a storyboard page, not
   one sketch; a mech, not a scavenger) — noted per test.
9. **Timeline bin shows prompts, not titles.**
10. **A compare sheet's name contains both titles**, so a title search also finds the sheet.
11. **Storyboard crops keep the panel numbers.**
12. **Qwen Instruct often returns the source unchanged** when asked for a big re-presentation of a picture it made
    itself: FTW-IMG-06 (all three), AUT-IMG-02, AUT-IMG-03, AUT-IMG-06; MOV-IMG-06 (a photo) barely changes. Each
    further Qwen pass adds a crunchy texture (AUT-IMG-07, GAM-IMG-08). Worth a look at Darkroom's Qwen Edit graph
    (reference strength / denoise) before calling it a model limit.
13. **Edit keeps the source's shape.** MOV-IMG-01's portrait storyboard page gave a portrait "widescreen" keyframe,
    and every Movie video built on it is portrait. An aspect choice in Instruct would fix this.
14. **The Orbit camera preset gave a pull-back** (GAM-VID-04), and "Static" still pushed in (GAM-VID-01).
15. **Cropped sources are small** (AUT-VID-02 383×214, AUT-VID-03 450×260); Video does not warn about a low-res start
    frame.

## 5. Bugs

- **Darkroom:** none crashed, no item went missing, every setting applied (checked in the settings screenshots). The
  seed-lock reset was the only real bug and is fixed (v3.20).
- **Test runner** (not Darkroom; all fixed and re-run):
  - it picked a compare sheet as an end frame (search matched both titles) — the wrong clip is kept, titled
    "WRONG END FRAME", not scored;
  - its Library search stayed scoped to one board, so the first Phase B attempt for Footwear/Gaming/Movie found no
    sources;
  - it saved 11 compare sheets into the working board (Automotive) under the default name — moved to their boards
    and renamed;
  - the outpaint padding read 0 (it looked for a size line that is not on the Outpaint panel) — MOV-IMG-03 re-run.
